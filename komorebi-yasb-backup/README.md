# Komorebi + YASB Backup

Personal Windows desktop configuration backup.

## Contents
- komorebi/: Komorebi configuration
- yasb/: YASB configuration, styles, notes, Launchpad and icons
- whkd/: WHKD hotkeys
- yasb-appdata/: Additional YASB settings
- historical/: Previous configuration snapshots

Logs, temporary files, sockets and installers are excluded.
